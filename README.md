# Vexta Intelligence — GitHub Pages

Sube todos los archivos de esta carpeta a la raíz de tu repositorio. Luego activa **Settings → Pages → Deploy from a branch → / (root)**.

Este paquete es la versión web. Para abrir el dashboard directamente desde una Mac sin publicarlo, usa el paquete local y haz doble clic en su `index.html`.

El simulador permite elegir Compra o Alquiler, ingresar un único precio en USD o PEN y recibir una recomendación estratégica específica para la operación. El tipo de cambio es editable.

Desde el resultado puedes compartir una ficha de negociación o imprimirla/guardarla como PDF para una reunión presencial.
